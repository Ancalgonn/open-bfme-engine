# Project status

OpenBFME is an experimental alpha. The importer and a large part of the
single-player skirmish runtime exist, but the project is not ready for a normal
release.

## At a glance

| Area | Status |
|---|---|
| BFME2 1.06 file discovery and local conversion | Completed |
| Private content-pack format and loading | Completed |
| Main menu, settings, and skirmish setup | In progress |
| Men versus Men on Fords of Isen II | In progress |
| Full Men roster | In progress |
| Elves, Dwarves, Isengard, Mordor, and Goblins | In progress |
| Additional skirmish maps | In progress |
| AI opponents | In progress |
| Multiplayer and dedicated servers | Not started |
| Replays and observers | Not started |
| Create-a-Hero | Not started |
| Public installer | Not started |

## What works today

- BFME2 data can be discovered, extracted, converted, and stored locally.
- The Godot runtime can load generated private content packs.
- Men versus Men on Fords of Isen II is the most developed playable slice.
- Core RTS systems include selection, movement, construction, production,
  combat, upgrades, formations, powers, heroes, AI, and match outcomes.
- Work is underway for all six BFME2 factions and a five-map development set.

## Known problems

- Faction test suites still contain failures.
- The interface is being rewritten and may change or break between commits.
- Fords of Isen II has better visual coverage than the other development maps.
- Some spellbook, unit-registration, animation, and cleanup tests still fail.
- Cross-faction skirmishes are not ready.
- The statistics screen is a placeholder.
- Multiplayer has not been implemented.
- There is no polished installer or supported public release.

## Current focus

1. Finish the interface rewrite.
2. Stabilize Men versus Men on Fords of Isen II.
3. Fix the remaining faction, spellbook, animation, and cleanup failures.
4. Improve the other development maps.
5. Complete visual review against BFME2 1.06.

Campaigns and War of the Ring are outside the project scope.
